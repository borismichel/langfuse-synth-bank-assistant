Customer assistant · Judge comparison

Application experiments

Compare exact prompt versions on a fixed cohort using retrieval and isolated banking tools. Native prompt-only experiments do not replay this application flow.

Both arms use the deployment’s primary model. Each comparison replays 10–16 cases per arm, sequentially, with up to 480 total model calls and a 10-minute deadline. Five policy judges evaluate the actual answer and approved evidence. Reference labels are constructed fixtures.

Cancellation stops new calls. An in-flight call may finish and remain billable. Refresh native evidence after ingestion; missing or uncertain mandatory results cannot pass. A failed baseline control also blocks approval.
